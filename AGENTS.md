# User preferences

- Do not spawn or use sub-agents unless the user explicitly asks for them.
- Commit and push ordinary changes in small, logical commits to the working branch.
- Do not add `Co-Authored-By` or generated-by trailers to commits or PR descriptions.
- Ask before changes to `main`, deployments, deletion, or rewriting Git history, unless already explicitly authorized.
- Never commit `.env`, tokens, private databases, or channel exports.
